# P2-XP011 fitness experiment

## Goal

Assess the tolerance of selected Vicia faba genotypes to A. fabae or A. pisum. By comparing the (i) number of seeds, (ii) total weight of the seeds produced and (iii) quality of the seeds produced (NIRS, germination rate) on plants infested vs non-infested plants. 

## Protocol

Sowing on Feb. 28 of the 20 seeds of each selected genotype.
4 selected genotypes: 
- One partially resistant (PR) for Aphis fabae.  
- One sensitive (S) for A. fabae. 
- One partially resistant (PR) for Acyrthosiphon pisum.  
- One sensitive (S) for A. pisum. 

Each genotype has two 3x3x2m cages with an insect-proof net:  
- One cage without aphid. 
- One cage with 3 adult aphid placed on each plant.  

Pollination will be done by bumble bees. 

Aphid infestation will be done at the 12-leaf stage with 3 adult aphids per plant. Each adult aphid is a G2 from a synchronised L1-G1 larvae.
