# README 

filtering_the_screening_dataset_aphis_fabae.qmd is the script allowing to filter
the dataset. 

aphis_fabae_data_filtered_4.csv is the output and the filtered dataset 
with min rep per genotype = 4

aphis_fabae_data_filtered_5.csv is the output and the filtered dataset 
with min rep per genotype = 5

aphis_fabae_data_filtered_6.csv is the output and the filtered dataset 
with min rep per genotype = 6


Most genotype have more repetition (~11), the minimal number of reps only concern a few 
genotypes for which we did not have enough data.
